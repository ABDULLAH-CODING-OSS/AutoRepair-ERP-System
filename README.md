# AutoRepair ERP System

## Overview

AutoRepair ERP System is a web-based Enterprise Resource Planning (ERP) solution developed using ASP.NET Core MVC and Microsoft SQL Server.

The system manages:

* User and Role Management
* Employee Management
* Customer Management
* Vehicle Registration
* Service Management
* Job Orders
* Inventory and Stock Management
* Suppliers
* Purchase Orders
* Attendance Tracking
* Payroll Processing
* Invoices and Payments
* Notifications
* Audit Logs

## Technology Stack

* ASP.NET Core MVC
* Entity Framework Core
* Microsoft SQL Server
* Bootstrap
* HTML/CSS/JavaScript
